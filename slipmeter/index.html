Questions, answered

What coaches want to know before they start.

SlipMeter is deliberately simple to begin with, but it can support much more disciplined reporting as your practice grows.

Ask a different question
Can I use SlipMeter without ClickCoach?

Yes. Standalone mode lets you create local clients and activities, save slips, run reports, and export your data without a ClickCoach account.

What happens when I connect ClickCoach?

SlipMeter can use eligible ClickCoach clients and activities. Saved slips can sync back to ClickCoach for centralized reporting and later operational workflows.

What happens if I close the app while a timer is running?

SlipMeter warns you before closing. The current elapsed time is stopped and the slip is saved so active work is not silently lost.

Can I correct a time entry?

Yes. You can edit elapsed time before saving, and use the slips view to review record status and make supported corrections.

Can a team combine SlipMeter records?

Yes. Standalone users can export records for consolidation, while ClickCoach organizations can centralize eligible slips and report across participating team members.

Does SlipMeter work on Windows?

The current public release is for Apple silicon Macs. Windows is not supported by this release.

Is the Mac app safe to install?

The distributed Mac installer is code-signed and notarized through Apple. macOS can verify the developer signature before installation.
